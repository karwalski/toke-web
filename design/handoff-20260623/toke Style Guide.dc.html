01 — The idea

A token is currency. Spend it well.

Every time an LLM writes code it emits one token at a time, and each one costs compute, time, and money. toke treats the token as what it really is — a coin. The whole identity runs on that metaphor: the minted coin, the arcade payout, the admit one ticket. Value, earned and not wasted.

Gold is the obvious carrier for that idea, and it does something useful too: it shines on the dark, terminal-toned surfaces where developers actually live. The palette is built dark-first for exactly that reason, with a warm light mode for docs and marketing.

05 — Code & syntax

Setting toke code

Code is the product, so it gets a restrained, three-colour scheme — gold for sigils & keywords, teal for types & values, muted for punctuation. Never rainbow-highlight; the economy of the language should read in the economy of its colour.

sum.tk 13 toke tok 
m=sum;
f=sum(arr:@i64):i64{
  $t:i64=0;
  <t;};

<0; is return 0; — 4 tokens become 1 — and the close pattern <0;} collapses to a single token under toke's purpose-built BPE tokenizer.

06 — Voice & persona

Terse. Exact. Dry.

toke strips ceremony out of code; the copy strips it out of language. We practise what the compiler preaches — say it in the fewest words that stay precise. A senior engineer who has stopped trying to impress you and just tells you the number.
