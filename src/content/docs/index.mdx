## The Problem

Every time an AI writes code, it generates one token at a time. Each token costs compute, time, and money. Today's programming languages were designed for humans — they're full of verbose keywords, boilerplate imports, and ceremony that LLMs must produce token by token.

**toke** is a programming language designed from first principles to minimise the number of tokens an LLM needs to generate. The result: AI writes equivalent programs using 2-4x fewer tokens than C or Java, directly reducing inference cost and latency.

<div class="explainer">
  <p><strong>What is a token?</strong> LLMs don't read characters — they read <em>tokens</em>, which are chunks of text (roughly 3-4 characters each). The word <code>return</code> is one token. The keyword <code>&lt;</code> in toke means the same thing but is also one token — saving 5 characters of output every time the AI returns a value.</p>
</div>

## Why This Matters

<CardGrid>
	<Card title="3-9x fewer tokens" icon="rocket">
		AI generates toke programs using a fraction of the tokens needed for C or Java. The purpose-built tokenizer achieves ~9x vs C, ~6x vs Java, ~3.5x vs Python for complete programs — measured across 46,730 verified programs in the training corpus.
	</Card>
	<Card title="Designed for correctness" icon="puzzle">
		LL(1) grammar, 12 keywords, minimal character set (56 characters). No ambiguity, no implicit coercions, full static type checking. The compiler catches mistakes before code runs — critical when AI is writing the code.
	</Card>
	<Card title="Standard library with C runtime" icon="pencil">
		11 standard library modules with C runtime implementations — strings, files, JSON, HTTP, database, crypto, environment, process, logging, time, and testing. Common operations become single function calls, shrinking token counts — and the AI learns optimised, tested implementations rather than reimplementing from scratch.
	</Card>
	<Card title="Open source" icon="open-book">
		MIT and Apache 2.0 licensed. Built in public. Every component — <a href="https://github.com/karwalski/tkc">compiler</a>, <a href="https://github.com/karwalski/toke-spec">spec</a>, <a href="https://github.com/karwalski/toke-corpus">corpus</a>, <a href="https://github.com/karwalski/toke-tokenizer">tokenizer</a>, <a href="https://github.com/karwalski/toke-benchmark">benchmarks</a> — is open for contribution and enterprise use.
	</Card>
</CardGrid>

## Quick Example

```
M=hello;
I=io:std.io;

F=main():i64{
  io.println("Hello, world!");
  <0;
};
```

A complete toke program. `M=` declares the module. `I=` imports a library. `F=` declares a function. `<` returns a value. Every statement ends with `;`. No boilerplate, no ceremony.
