## The Problem

LLMs generate code token by token. Every token costs time and money. Languages like Python use **3-5x more tokens** than necessary to express the same logic — verbose keywords, deep indentation, boilerplate imports.

**toke** is designed from first principles to minimise token count while remaining human-readable and writable. The same program that takes 156 tokens in Python takes 47 in toke.

```
M=fib;
F=fib(n:i64):i64{
```

## Why This Matters

## Quick Example

```
M=hello;
I=io:std.io;

F=main():i64{
  io.println("Hello, world!");
  <0;
};
```

This is a complete toke program. `M=` declares the module. `F=` declares a function. `<` returns a value. `if(){}` branches. `;` terminates everything.
