toke program library

Every verified toke program, by category — with inputs, expected outputs, and a token comparison vs Python.

How to read these numbers. Token counts are real: toke source is measured with the toke BPE tokenizer (v03, 16,384 vocab), Python with cl100k_base. These corpus programs are generated and repaired for correctness, not hand-optimised for tokens — so many use more tokens than idiomatic toke would. The headline efficiency claims elsewhere on the site come from the curated benchmark suite, not this corpus. Shown honestly: toke is the more compact encoding in roughly a quarter of these programs.

Units: tok = BPE tokens · B = source bytes. Ratio > 1 = toke fewer; < 1 = toke more.
