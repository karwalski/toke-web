Loke — toke on the desktop

Loke is the desktop companion for the toke language. Install once, get a local compiler, language server, and MCP server for AI-assisted development.

Sign up for early access Learn about toke

Everything you need, locally

▶

Local compiler

The full toke compiler runs on your machine. Compile and run toke programs instantly, no cloud required.

■

VS Code integration

Syntax highlighting, error checking, and code completion for .tk files via the Loke language server.

◆

MCP server

Exposes a local MCP server so AI assistants can read, write, and compile toke programs in your workspace.

●

Auto-updates

Loke keeps itself and the toke toolchain up to date automatically. Always on the latest stable release.

Early access

Loke is in development alongside the toke Phase 2 toolchain. Sign up to be notified when the first build is ready.
