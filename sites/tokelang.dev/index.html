toke — a compact
systems language

toke is a compiled, statically-typed language with a compact syntax designed for AI-generated code. Programs are shorter, faster to generate, and still readable.

Get started View on GitHub
-- hello world in toke m=hello; i=fmt:std.fmt; f=greet(name:str):str{ "Hello, "+name+"!" }; f=main():i64{ fmt.println(greet("world")); <0 };

Why toke?

■

Compact syntax

Designed for AI code generation. Every construct is short, unambiguous, and consistent — no syntactic noise, no optional sigils.

◆

LLVM-compiled

Compiles to native machine code via LLVM. Fast binaries, small footprint, runs anywhere LLVM targets.

●

Rich stdlib

Standard library covers HTTP, JSON, file I/O, cryptography, environment, strings, and more — all with the same compact import style.
