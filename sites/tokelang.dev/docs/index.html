Get up and running with toke.

Quick start

1. Write a program

Create a file named hello.tk:

m=hello; i=fmt:std.fmt; f=main():i64{ fmt.println("Hello, world!"); <0 };

2. Compile

tkc --out hello hello.tk

3. Run

./hello

Example: simple web server

m=server; i=http:std.http; f=main():i64{ http.handle("/"; index); http.serve(8080); <0 }; f=index(req:http.Req; res:http.Res):{ res.text("Hello from toke!") };

Standard library modules

Import any module with i=alias:std.module; and call it as alias.function().

Full documentation

Complete API reference, language specification, and interactive examples are available at console.tokelang.dev.

Language reference

Module declaration

m=mymodule;

Import

i=alias:std.module;

Function

f=name(param:type):returntype{body};

Variable

v=name:type=value;

Return

<expression

Conditionals

?(condition){then}{else}

Loop

@(i=0; i<10; i=i+1){body}
